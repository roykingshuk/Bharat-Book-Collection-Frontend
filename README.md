# Bharat Book Collection – Frontend

A sample book store application built as part of a B.Tech 6th Semester Project. This frontend showcases book browsing, details, user authentication, and a dashboard interface.

🔗 **Live Demo**: [Deployed on Render](https://bharat-book-collection-1-0.onrender.com)

---

## 🧰 Technologies Used
- **HTML5**, **CSS3** (LESS, SCSS)
- **Bootstrap** for responsive, mobile-first design  
- **JavaScript**, powered by **jQuery AJAX** for frontend interactivity and data handling  
- Structured components: `index.html`, `bookdetails.html`, `dashboard.html`, `login.html`, and `signup.html` 

---

## 🚀 Features
- **Home Page**: Browse featured and latest books  
- **Book Details Page**: View comprehensive book information  
- **User Auth**: Includes signup and login modals/pages  
- **Dashboard**: Admin-like interface for book collections  
- **Responsive Design**: Adaptable layout across devices  
- Clean codebase modularized into folders: HTML, CSS, JS, fonts, images
